# ۱۲ شب – نسخهٔ دیجیتال

در این مخزن، نسخهٔ دیجیتال بازی «۱۲ شب» و ویرایشگر آن قرار دارد. بازی برای جمع‌های حضوری ساخته شده است: کامپیوتر ویندوزی صفحهٔ مشترک بازی (مانیتور) را نشان می‌دهد و هر بازیکن با گوشی اندرویدی خودش بازی می‌کند. همه در یک شبکهٔ محلی هستند و به اینترنت نیازی نیست.

## چیزهایی که در مخزن هست

| پوشه | محتوا |
|---|---|
| `data/game.json` | **همهٔ داده‌های بازی**: کارت‌ها، جادوگران، اهریمن‌ها، تایل‌ها، قانون‌ها و عددها، متن‌ها، رنگ‌ها و فهرست گرافیک‌ها |
| `data/art/` | گرافیک‌هایی که در ویرایشگر آپلود شده‌اند |
| `editor/index.html` | **ویرایشگر** (یک فایل؛ در مرورگر باز می‌شود) |
| `game/` | برنامهٔ بازی: موتور بازی، سرور میزبان، صفحه‌های مانیتور و گوشی |
| `android/` | برنامهٔ اندروید |
| `.github/workflows/build.yml` | ساخت خودکار zip ویندوز و APK |

## کار با ویرایشگر

1. فایل `editor/index.html` را دانلود کن و در Chrome یا Edge باز کن. نسخهٔ آنلاینش هم در claude.ai هست.
2. هر چیزی را که لازم است عوض کن: جدول‌ها، تایل‌ها، گرافیک‌ها، متن‌ها، رنگ‌ها و عددهای قانون. تغییرها خودکار در همان مرورگر ذخیره می‌شوند.
3. در «پیش‌نمایش زنده»، کل بازی را با تغییرهایت امتحان کن: یک مانیتور و ۲ تا ۵ گوشی، با رباتی که خودکار بازی می‌کند.
4. در «ساخت و انتشار»، اول «بررسی کن» را بزن، بعد «ثبت و ساخت» را. حدود ۱۰ دقیقه بعد، نسخهٔ تازه در صفحهٔ **Releases** همین مخزن آماده است: یک zip برای ویندوز و یک APK برای اندروید.

شمارهٔ نسخه را در «قانون‌ها و عددها» ← «نسخه» بالا ببر، مثلاً از 1.1.0 به 1.2.0.

### توکن گیت‌هاب برای دکمهٔ «ثبت و ساخت» (فقط یک بار)

1. به github.com/settings/personal-access-tokens/new برو.
2. یک نام بنویس و زمان انقضا را مثلاً یک سال بگذار.
3. در Repository access گزینهٔ «Only select repositories» را انتخاب کن و همین مخزن را بردار.
4. در Permissions ← Repository permissions، گزینهٔ **Contents** را روی **Read and write** بگذار.
5. Generate token را بزن و توکن را در ویرایشگر، بخش «ساخت و انتشار»، بنویس. توکن فقط در همان مرورگر ذخیره می‌شود.

**بدون توکن:** در ویرایشگر «گرفتن zip» را بزن و فایل را باز کن. بعد در گیت‌هاب، در صفحهٔ اصلی مخزن، Add file ← Upload files را بزن و پوشهٔ `data` را روی صفحه بکش. ساخت خودکار بعد از آپلود شروع می‌شود.

### کلید امضای اندروید (فقط یک بار)

APK با همان کلید نسخه‌های قبلی امضا می‌شود تا روی نسخهٔ نصب‌شده نصب شود. این کلید در مخزن نیست:

1. در مخزن به Settings ← Secrets and variables ← Actions برو.
2. New repository secret را بزن و نامش را `KEYSTORE_B64` بگذار.
3. مقدارش را متن فایل `KEYSTORE_B64.txt` بگذار. Claude این فایل را در پوشهٔ پروژه گذاشته است.

اگر این کلید نباشد، zip ویندوز باز هم ساخته می‌شود، ولی APK ساخته نمی‌شود.

## چه چیزهایی بدون برنامه‌نویسی عوض می‌شوند

- **کارت‌های آکادمی:** کارت تازه، حذف و کپی کارت، و تغییر هزینه، قدرت، امتیاز، تعداد، متن و نوار سیاه‌چال. «گرفتن منبع»، «کشیدن کارت» و «شهرت فوری» برای هر کارتی کار می‌کنند. اثر ویژهٔ کارت را می‌توان از میان اثرهای موجود انتخاب کرد.
- **جادوگران:** جادوگر تازه، دفاع، قدرت، سطح، گروه و متن. اثر هر جادوگر یکی از کدهای `docs/WIZARD_EFFECTS.md` است.
- **بقیهٔ داده‌ها:** کارت‌های اهریمن و پاداش‌هایشان، اثرهای میدان نبرد، کیسهٔ گنجینه، نام و متن وسایل، توکن‌های چالش، ارتقاها و خاندان‌ها.
- **قانون‌ها و عددها:** اندازهٔ دست، ردیف آکادمی و تالار، ذخیره، شروع بازی، تاس‌ها، شب‌ها، نبردها و چالش‌ها بسته به تعداد بازیکن، دک آغازین، زخم، غنیمت سیاه‌چال، دوئل و نبرد جادوگران.
- **تایل‌های سیاه‌چال:** با ویرایشگر کامل تایل. تصویر هر تایل هم می‌تواند به بازی برود.
- **گرافیک:** تصویر هر کارت، جادوگر، اهریمن و تایل، پشت کارت‌ها، آیکون‌ها (از جمله گوبلین)، پس‌زمینه‌ها، فونت‌ها و آیکون برنامه.
- **ظاهر:** همهٔ متن‌های فارسی برنامه، همهٔ رنگ‌ها و CSS دلخواه.

**چیزهایی که هنوز برنامه‌نویسی لازم دارند:** اثرِ کاملاً تازه برای کارت یا جادوگر، وسیله یا چالش تازه که کار تازه‌ای می‌کند، و تغییر اساسی در روند بازی. این کارها را به Claude بسپار: فایل‌های `game/shared/engine.js`، `dungeon.js` و `battle.js` باید عوض شوند.

## برای برنامه‌نویس

```
node tools/build.js              # data/game.json -> game/shared/data.js
node tools/build.js dist         # copy of the game with texts, colours and art applied (dist/game)
node tools/build_editor.js       # editor/template.html -> editor/index.html
cd game && npm ci && node test/bot.js 40    # robot plays 40 full games
npm start                        # run the Windows app (Electron)
```
